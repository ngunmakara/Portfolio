CV / Resume placeholder
======================

Drop your real CV PDF here and update the file name to match.

The app is configured to link to this path:

  /files/NGUN_MAKARA_CV.pdf

If you name your file exactly NGUN_MAKARA_CV.pdf, no code changes are
needed. If you prefer a different name, update the cvUrl value in:

  src/data/siteConfig.js

Tip: keep the file name short and without spaces so the link works on
all browsers without issues.
